# PHYSICS MAKER

Қазақ тіліндегі интерактивті физика жобасы. Бұл бума GitHub репозиторийінің түбірі ретінде жариялауға дайын.

## Телефоннан сайтты дұрыс ашу

GitHub-тағы `index.html` файлының беті сайттың өзі емес, файлды қарау көрінісі. Сайтты `https://<пайдаланушы>.github.io/<репозиторий>/` түріндегі GitHub Pages сілтемесімен ашу керек.

1. Осы буманың **ішіндегі файлдарды** репозиторийдің түбіріне жүктеңіз. `outputs` деген ішкі бумаға салып жібермеңіз. Түбірде `index.html`, `app.js`, `style.css` және `assets` тұруы керек.
2. Репозиторийдің әдепкі тармағына (`main` немесе `master`) осы өзгерістерді сақтаңыз.
3. Репозиторийде **Settings → Pages → Build and deployment → Source** бөлімінен **Deploy from a branch** таңдаңыз.
4. **Branch** ретінде әдепкі тармақты, бума ретінде `/(root)` таңдап, **Save** басыңыз.
5. Pages бөлімі көрсеткен `https://<пайдаланушы>.github.io/<репозиторий>/` сілтемесін телефоннан ашып, сол сайт сілтемесін бөлісіңіз.

Суреттер `assets/` ішінен салыстырмалы жолмен ашылады. Формулаларды KaTeX CDN арқылы көрсету үшін интернет байланысы қажет.
